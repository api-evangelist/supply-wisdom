# Supply Wisdom

> Supply Wisdom is a third-party and location risk intelligence SaaS platform that continuously
> monitors suppliers, vendors and operating locations across financial, cyber, compliance, ESG,
> operational, nth-party and geopolitical risk. It is sold as three subscriptions — Real-time Alerts,
> Comprehensive Intelligence and Continuous Monitoring — and is designed to feed an organisation's
> existing GRC platform.

Generated by API Evangelist from the public Supply Wisdom surface on 2026-08-29. Supply Wisdom does
not publish an llms.txt of its own; /llms.txt returns 404 on www.supplywisdom.com and the SPA
catch-all shell on api./app.supplywisdom.com.

## API status

Supply Wisdom publishes **no public API**. There is no developer portal, no API reference, and no
machine-readable contract (OpenAPI, Swagger, GraphQL SDL, AsyncAPI, Protobuf, WSDL, MCP tools/list or
A2A agent card) on any Supply Wisdom host. The platform is a tenant application behind a login. The
product page advertises webhook notifications and GRC integration, but neither is documented publicly.
Do not attempt to construct calls against api.supplywisdom.com — it serves the customer web
application, not an API.
